Convert a Markdown outline into a self-contained HTML slide deck. No npm, build tools or Python packages.

## Features
- Split slides with a line containing three dashes.
- Headings, paragraphs and bullet lists.
- Arrow-key navigation, progress bar and fullscreen mode.
- One portable HTML file that works offline.

## Run
    python app.py --example
    python app.py presentation.md -o slides.html

Python 3.9+. Standard library only. MIT license.
